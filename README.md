# PROPLED – Property Ledger

### Property Ownership Management System

PROPLED (Property Ledger) is a web-based property ownership management system designed to improve transparency and simplify property transactions. It provides a centralized platform where users can explore property details, verify tax information, view historical ownership records, check partnership details, and submit property booking requests.

## 📌 Project Overview

Traditional property transactions often involve paperwork, fragmented records, and difficulties verifying ownership history and tax dues. PROPLED addresses these challenges by organizing property-related information in a centralized system, helping users make more informed decisions before booking a property.

## 🎯 Objectives

- Improve transparency in property transactions.
- Provide access to property tax and ownership history details.
- Support multiple partners associated with a property.
- Enable secure user registration and authentication.
- Simplify property searching, booking, and administration.

## ✨ Key Features

- **User Registration & Authentication:** Users can register and log in, subject to the required approval process.
- **Property Management:** Administrators can upload and manage property details.
- **Tax Information:** Users can search for property tax details.
- **Ownership History:** Access historical ownership records associated with properties.
- **Partner Details:** View partnership information related to a property.
- **Property Booking:** Browse available properties and submit booking requests.
- **Admin Dashboard:** Manage user approvals and property-related information.

## 🛠️ Technology Stack

- **Programming Language:** Java
- **Web Technology:** JavaServer Pages (JSP), HTML, CSS, JavaScript
- **Database:** MySQL
- **Development Environment:** NetBeans IDE

## ⚙️ System Workflow

1. Users register on the platform.
2. Administrators review and approve user registrations.
3. Administrators upload property, tax, previous-owner, and partner details.
4. Users search for properties and review the available information.
5. Users can submit booking requests for properties of interest.

## 🚀 Expected Benefits

- Better accessibility to property-related information.
- Improved transparency in property ownership records.
- Reduced dependence on manual record-keeping.
- More informed property booking decisions.
- Centralized management of property details.

## 🔮 Future Enhancements

Potential future enhancements include interactive property maps, augmented reality for property visualization, predictive analytics for property trends, personalized search filters, and notification features.
